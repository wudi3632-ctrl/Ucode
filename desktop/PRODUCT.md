# UCode Portable

UCode Portable is a lightweight, local-first Windows coding assistant designed to run from a USB drive. It gives developers a calm Codex-like conversation workspace for asking questions, understanding a project, reviewing plans, and approving controlled file changes.

## Product character

- Capable, calm, precise, and trustworthy.
- Conversation is primary; tools, diffs, and task progress support the answer instead of dominating it.
- Portable and offline-first behavior must remain visible without feeling technical or alarming.
- The interface should feel dense enough for professional work, but never crowded.

## Interaction principles

- The composer is always reachable, regardless of thread length or window size.
- Only the content region that owns overflow may scroll.
- Thinking, tool work, and task progress are progressively disclosed.
- File writes stay behind explicit approval.
- Small windows collapse secondary context before compromising the conversation.

## Visual direction

Use an original dark desktop interface inspired by the restraint and hierarchy of modern coding agents. Avoid copied branding, assets, or exact layouts. Prefer borderless assistant prose, compact user messages, quiet surfaces, subtle depth, and short purposeful motion.

## Anti-patterns

- The composer falling below the viewport.
- A permanently dominant inspector.
- Card-on-card dashboards, excessive borders, decorative gradients, or playful bounce.
- Raw tool JSON and implementation details in the conversation.
